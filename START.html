⚠️ Backend Not Running

Before accessing the store, you need to start the backend server.

Steps to Start:

  1. Open PowerShell / Terminal
  2. Navigate to backend:
    cd backend
  3. Install dependencies:
    npm install
  4. Start the server:
    npm start
  5. Wait for:
    "✅ Server running on http://localhost:5000"
  6. Then click "Launch Store" below
